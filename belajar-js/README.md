# 🗺️ Roadmap Belajar Fundamental JavaScript → React Native (Gaya OOP)

Materi dibahas **satu sub-bab per langkah**. Tiap sub-bab punya folder sendiri:

```
<sub-bab>/
├── materi.md   → penjelasan + contoh + soal latihan (+ kunci jawaban tersembunyi)
├── contoh.js   → contoh yang bisa langsung di-run
└── latihan.js  → TEMPAT LU NGERJAIN SOAL
```

## ▶️ Cara Latihan (pakai nodemon)

Jalankan dari root project:

```bash
npm run latihan -- belajar-js/01-fundamental-javascript/01-tipe-data/01-string/01-cara-menulis/latihan.js
```

Setiap kali file disimpan (`Cmd + S`), nodemon otomatis menjalankan ulang dan menampilkan hasilnya. Stop pakai `Ctrl + C`.

Kalau sudah selesai satu sub-bab, centang `[x]` di roadmap ini lalu minta sub-bab berikutnya.
